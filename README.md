# Shop Floor

A browser CNC mill simulator game. Write real G-code, watch it cut a block of aluminum in 3D, and ship parts that pass inspection.

```sh
npm install
npm run dev
```

## How it plays

Each job gives you a work order (stock size, target shape, tools) and a starter program. Edit the G-code, press **Cycle Start**, and the machine runs it line by line. When the program ends, the part is compared cell by cell with the target: 97% in tolerance (±0.1 mm) with under 1% gouged passes, and beating the par cycle time earns three stars.

Things that stop the machine, as on a real one:

- Rapid (`G0`) moves into material, cutting with the spindle off or with no tool loaded
- Holder collisions (cutting deeper than the flute length)
- Broken tools: too deep per pass, too much feed per tooth (`F ÷ (S × flutes)`), or drills moving sideways
- Moves past machine travel, and program errors (bad arcs, missing F, unreadable words)

Controls: Cycle Start (⌘/Ctrl+Enter), Feed Hold (Esc), Reset, Single Block, feed override 0–200%, rapid override, simulation speed, and Skip to end.

## Supported G-code

`G0 G1 G2 G3` (IJK or R arcs, helical), `G4`, `G17 G18 G19`, `G20 G21`, `G28`, `G73 G81 G82 G83` / `G80`, `G90 G91`, `G98 G99`, `M0 M1 M2 M3 M4 M5 M6 M8 M9 M30`, and `F S T`. Comments use `( )` or `;`. `G41/G42` and `G55–G59` produce a warning and are ignored. Work zero is the front-left corner of the top face.

## Structure

- `src/sim/`: the simulation, with no UI dependencies
  - `gcode.ts` reads programs into a flat list of moves and events
  - `stock.ts` is a 2.5D height map with exact swept-tool material removal (flat, ball, drill)
  - `machine.ts` plays moves back over time and raises alarms
  - `score.ts` compares the part to the target
  - `tools.ts` is the tool library
- `src/game/`: jobs (each target is generated by running a reference program) and saved progress
- `src/view/`: the three.js scene (stock mesh, tool, toolpath, chips) and synthesized sound
- `src/ui/`: React panels, with a CodeMirror G-code editor

## Known limits and next steps

- The height map can't represent undercuts. 4/5-axis work would need a voxel or dexel stock.
- There's no lathe yet. A radius-per-Z profile turned into a 3D shape would slot in next to `Heightmap`.
- Cutter compensation, work offsets beyond G54, tool length offsets and macros aren't simulated.

The original slider-based game is archived in `archive/shop-floor-v1.tar.gz`.

Simplified for learning and fun. Don't run these programs on a real machine without checking them.
